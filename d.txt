PARTIE 3 — ÉTUDE DE CAS )

Q1) Installez Git et, à l'aide de « git help », trouvez la commande qui permet d'afficher l'état de la copie de travail.
Answer:
git status

Q2) Initialisez votre identité Git (nom et adresse email).
Answer:
git config --global user.name "Votre Nom"
git config --global user.email "email@example.com"

Q3) Vérifiez votre identité.
Answer:
git config --global user.name
git config --global user.email

Q4) Créez un dossier dep2 sur votre ordinateur.
Answer:
mkdir dep2
cd dep2

Q5) Initialisez un dépôt Git dans le répertoire dep2.
Answer:
git init -b master

Q6) Créez un fichier HOME.html à la racine de votre dépôt Git avec votre nom et prénom.
Answer:
cat > HOME.html <<'EOF'
<!DOCTYPE html>
<html>
<head>
<title>Info</title>
</head>
<body>
Votre nom et prénom
</body>
</html>
EOF

Q7) Visualisez l'état de votre suivi Git.
Answer:
git status

Q8) Ajoutez le fichier HOME.html à la staging area.
Answer:
git add HOME.html

Q9) Vérifiez que le fichier HOME.html a bien été ajouté à la staging area.
Answer:
git status

Q10) Validez les modifications avec le message « Ajouter README ».
Answer:
git commit -m "Ajouter README"

Q11) Ajoutez votre email au fichier HOME.html.
Answer:
cat > HOME.html <<'EOF'
<!DOCTYPE html>
<html>
<head>
<title>Info</title>
</head>
<body>
Votre nom et prénom
Votre email
</body>
</html>
EOF

Q12) Validez cette nouvelle modification avec le message « Ajouter email à REAME ».
Answer:
git add HOME.html
git commit -m "Ajouter email à REAME"

Q13) Affichez ce qui a été modifié dans le fichier HOME.html.
Answer:
git show HEAD -- HOME.html

Q14) Affichez l'historique des commits.
Answer:
git log

Q15) Créez une nouvelle branche nommée mybranche.
Answer:
git branch mybranche

Q16) Vérifiez que la nouvelle branche mybranche a été créée.
Answer:
git branch

Q17) Changez de branche vers mybranche.
Answer:
git switch mybranche

Q18) Ajoutez le code postal de votre ville au fichier HOME.html.
Answer:
cat > HOME.html <<'EOF'
<!DOCTYPE html>
<html>
<head>
<title>Info</title>
</head>
<body>
Votre nom et prénom
Votre email
Code postal : 70000
</body>
</html>
EOF

Q19) Validez cette nouvelle modification avec le message « Ajouter cp à REAME ».
Answer:
git add HOME.html
git commit -m "Ajouter cp à REAME"

Q20) Fusionnez la branche mybranche vers la branche master.
Answer:
git switch master
git merge mybranche







































Q1) Donner les 5 piliers fondateurs de la culture DevOps.

Culture : collaboration.
Automation : automatisation.

Réduction des coûts.
Accès à distance.
Évolutivité des ressources.
Haute disponibilité.

PARTIE 2 — QUESTIONS À CHOIX MULTIPLE (05 pts)

Q1) Lorsque vous ajoutez une pile de logiciels, telle qu'un système d'exploitation et des applications, on parle du modèle _____.
Answer: IaaS.

Q2) Quelle est la commande Git qui télécharge votre référentiel de GitHub sur votre ordinateur ?
Answer: git clone

Q3) Quelle est la commande MS-DOS qui permet d'avoir la version de Maven installée ?
Answer: mvn -version ; mvn --version

Q4) Quelle est la commande MS-DOS qui permet de lancer la phase de test sur Maven ?
Answer: mvn test
